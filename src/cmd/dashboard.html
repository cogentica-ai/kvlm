From measurement to action

one decode step for the whole batch: the GPU runs these kernels top to bottom, repeats that for every layer, and the whole thing replays as a single CUDA graph launch. Bar length compares each kernel's time within one layer; the longest bar is where the step is spent. Verdicts, in plain terms: waiting on memory = the time goes to re-reading the weights, faster memory helps, more compute does not; scales with load = it does more work as the batch grows; too small to fill the GPU = a tiny launch, most of the chip idles for it.
